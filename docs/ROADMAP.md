# Roadmap

## Phase 1 — playable foundation
- [x] Canvas arena and neon visual system
- [x] Movement and nearest-target auto-fire
- [x] Four enemy archetypes
- [x] Scrap pickups, levels, and upgrade choices
- [x] Combo, score summary, and local best score
- [x] Basic Cosmic Storm and closing danger boundary
- [x] Local meta upgrades and offline scrap
- [x] Responsive HUD and touch movement

## Phase 2 — quality and balance
- [ ] Automated unit and browser tests
- [ ] Profile 500+ enemies and pool hot-path objects
- [ ] Balance health, enemy density, XP curve, and storm frequency with playtests
- [ ] Add sound toggle, audio cues, and reduced-flash setting
- [ ] Improve pause state and accessible focus handling
- [ ] Add save migration and reset/export controls

## Phase 3 — content and portability
- [ ] Add orbiting shield and chain-lightning upgrade families
- [ ] Add seedable runs and daily challenge mode
- [ ] Add touch joystick and mobile performance testing
- [ ] Evaluate Steam packaging and platform requirements
- [ ] Consider cosmetic collection only after core gameplay is stable

## Release gates
Do not claim stable 60 FPS or thousands of simultaneous entities without profiling on representative devices. Any marketplace/Steam economy requires separate platform review and must remain cosmetic-only.
