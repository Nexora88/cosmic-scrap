# Roadmap

## Phase 1 — playable foundation
- [x] Canvas arena, movement, auto-fire, four enemy archetypes
- [x] Scrap pickups, level choices, combo, score, meta progression
- [x] Responsive HUD and touch movement

## Phase 2 — quality pass (implementation underway)
- [x] Reuse pools for enemies, projectiles, particles and XP orbs
- [x] Add orbiting shield, chain lightning, ion trail and nova burst upgrades
- [x] Add Web Audio cues and a sound toggle
- [x] Add pause overlay, resume/menu flow and focus handling
- [x] Add v1-to-v2 save migration, JSON import/export and reset
- [x] Add virtual joystick for mobile touch controls
- [x] Add reduced-motion styling and conservative entity caps
- [ ] Run automated/browser tests and profile representative devices
- [ ] Playtest XP, enemy scaling, storm frequency and upgrade balance
- [ ] Add explicit reduced-flash option and further accessibility checks

## Phase 3 — content and portability
- [ ] Seedable runs and daily challenge mode
- [ ] Evaluate Steam packaging and platform requirements
- [ ] Consider cosmetic collection only after core gameplay is stable

## Release gates
Implementation is not the same as validation. Do not claim stable 60 FPS without profiling representative devices. Marketplace/Steam economy requires separate platform review and must remain cosmetic-only.
